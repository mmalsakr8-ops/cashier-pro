Cashier Pro — نظام إدارة المطاعم والكافيهات

المشروع مجهز للمستودع الجديد cashier-pro وقاعدة Cloudflare D1 المسماة cashier-pro-db.

المزايا الموجودة في هذه الحزمة:
- إنشاء حساب وتسجيل الدخول والخروج.
- إعداد بيانات المطعم أو الكافيه.
- إدارة المنتجات والأصناف والأسعار.
- إنشاء فواتير بعناصر وكميات وخصم وضريبة وخدمة وطريقة دفع وطاولة/نوع طلب.
- حفظ الفواتير وتفاصيلها، ومعاينة الفاتورة وطباعتها أو حفظها PDF من المتصفح.
- تقارير المبيعات وتصدير CSV.
- تسجيل المصروفات وإغلاق اليوم وسجل عمليات أساسي.
- قاعدة بيانات SQL وفهارسها.

إعدادات Cloudflare مضبوطة على:
- Worker: cashier-pro
- D1 database: cashier-pro-db
- D1 ID: 4b28d1c2-e5fa-43e5-b388-7eab86531c1a
- binding: DB

خطوات النشر:
1. ارفع ملفات هذه الحزمة إلى مستودع GitHub الجديد: https://github.com/mmalsakr8-ops/cashier-pro
2. تأكد أن Cloudflare Worker cashier-pro متصل بالمستودع الصحيح أو انشر من مجلد المشروع باستخدام Wrangler.
3. نفّذ مخطط قاعدة البيانات على قاعدة D1 البعيدة:
   npx wrangler d1 execute cashier-pro-db --remote --file=./schema.sql
4. ثبّت Wrangler إذا لزم:
   npm install -D wrangler
5. انشر المشروع:
   npx wrangler deploy
6. افتح رابط Worker وأنشئ الحساب، ثم أدخل بيانات المطعم.

ملاحظات مهمة:
- يعمل النظام على HTTPS، وهو مناسب لرابط Cloudflare Worker.
- QR والطباعة يعتمد بعضهما على المتصفح والإنترنت حسب الاستخدام.
- راجع إعدادات الضريبة والخدمة وفق المتطلبات المصرية قبل الاعتماد المالي.
- هذه نسخة أولية قابلة للاختبار وليست شهادة امتثال ضريبي أو اعتمادًا للفوترة الإلكترونية.
- يجب اختبار التسجيل والفواتير والتقارير والطباعة على بيئة تجريبية قبل الاستخدام الفعلي.
- لوحة الإدارة المركزية للاشتراكات وتعدد الفروع والصلاحيات التفصيلية ليست منفذة في هذه النسخة.

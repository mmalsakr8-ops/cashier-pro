ملاحظات قاعدة البيانات
======================

قاعدة البيانات الحالية تُترك كما هي. لا تستخدم DROP TABLE أو تحذف قاعدة D1.

يقوم worker.js بفحص أعمدة الجداول المعروفة عند طلب API، ويضيف الأعمدة الاختيارية الناقصة عبر ALTER TABLE فقط. كما يملأ حقول التوافق للفواتير والمصروفات القديمة عند إضافة هذه الحقول لأول مرة.

الجداول الأساسية المتوافقة:
users, sessions, restaurants, products, invoices, invoice_items, expenses, daily_closings, audit_logs

أسماء الحقول الأساسية في قاعدة البيانات الحالية تشمل:
- invoices.invoice_number (وليس invoice_no فقط)
- invoices.tax وinvoices.service
- invoice_items.product_name
- daily_closings.closing_date وtotal_sales وtotal_expenses وcash_total وcard_total

لا حاجة لتنفيذ SQL يدوي لهذا الإصدار.

ميزة طباعة أقسام المطبخ والبار:
- يضيف worker.js عمود products.station عند الحاجة، والقيمة الافتراضية kitchen.
- ينشئ جدول order_tickets وجدول order_ticket_items وفهرس الطابور باستخدام CREATE TABLE/INDEX IF NOT EXISTS.
- لا تشغّل SQL يدويًا؛ الترحيل يتم تلقائيًا من worker.js ويحافظ على البيانات الحالية.
- الطباعة الصامتة التلقائية تتطلب إعداد الجهاز والمتصفح كما هو موضح في README_AR.txt؛ الكود وحده لا يستطيع اختيار طابعة نظام محددة من المتصفح.
